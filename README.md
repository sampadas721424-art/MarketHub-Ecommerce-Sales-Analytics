# MarketHub – E-commerce Sales Analytics

## About

MarketHub is an e-commerce sales analytics project built using MySQL and Power BI.

The project focuses on analyzing customers, products, orders, and sales data.

## Tools Used

- MySQL
- MySQL Workbench
- SQL
- Power BI
- GitHub

## Database Tables

- Customers
- Categories
- Products
- Orders
- OrderItems

## SQL Work

I created SQL queries to analyze:

- Total sales
- Customer spending
- Product sales
- Popular categories
- Monthly orders
- Recent orders
- Out-of-stock products

I also created **Views** and **Stored Procedures** for the database.

## Power BI Dashboard

The Power BI dashboard shows:

- Total Sales
- Sales by Customer
- Sales by Category
- Sales Trend Over Time
- Order Details

The database relationships are shown in the ER diagram included in this repository.
